# Бюджет на двох: Telegram-бот + monobank

Спільний бюджет на місяць для двох. Покупки з карток monobank додаються самі одразу після оплати, а бот пише про кожну з кнопками, щоб змінити категорію. Готівку та інше вносиш повідомленням боту («350 кафе»). Повний застосунок відкривається прямо в Telegram кнопкою «Бюджет».

Працює на Cloudflare Workers (безкоштовний тариф із великим запасом). Власний сервер не потрібен.

## Встановлення (≈10 хвилин)

1. **Створи бота.** У Telegram відкрий @BotFather → `/newbot` → придумай назву та юзернейм, що закінчується на `bot`. Скопіюй токен (вигляд `123456:ABC…`).
2. **Зареєструйся в Cloudflare** на dash.cloudflare.com. Це безкоштовно, картка не потрібна.
3. **Запусти в терміналі:**
   ```bash
   cd "budget-bot"
   ./setup.sh
   ```
   Відкриється браузер для входу в Cloudflare. Потім скрипт попросить вставити токен бота.
4. Відкриється сторінка з **посиланням-запрошенням**. Відкрий його на телефоні, натисни «Я — Вадим». Потім перешли це ж посилання дівчині: вона натисне свою кнопку. Більше ніхто приєднатися не зможе.
5. **Підключи monobank:** у боті натисни «💳 Mono» і виконай інструкцію (нижче). Дівчина робить те саме зі свого телефона для своїх карток.

## Де взяти токен monobank

1. Відкрий **https://api.monobank.ua/**, найзручніше з компʼютера.
2. Натисни «Отримати токен», відскануй QR-код камерою в застосунку monobank і підтвердь вхід.
3. Скопіюй токен зі сторінки (довгий рядок, зазвичай починається на `u`).
4. Надішли його боту одним повідомленням. Бот одразу видалить повідомлення з токеном, покаже твої картки, підтягне витрати з 1-го числа і далі отримуватиме кожну покупку в реальному часі.

Токен дає тільки перегляд виписки та балансу, переказати ним гроші неможливо. Відкликати його можна на тій самій сторінці.

## Як користуватись ботом

| Пишеш | Що буде |
|---|---|
| `350 кафе`, `кава 85` | витрата 350 ₴ у «Кафе» |
| `1200 сільпо` | «Продукти» (магазин розпізнається) |
| `20$ steam` | у доларах за курсом monobank |
| `6000 дім разова` | разова покупка: не зменшує місячний залишок |
| `500 подарунок окремо` | окремо, не зі спільного бюджету |
| 📊 Залишок | скільки вільно, скільки можна на день, прогноз |
| 📋 Останні / 🗂 Категорії | список і ліміти |
| `/budget 44000`, `/rate auto`, `/daily off`, `/web` | бюджет, курс, вечірній підсумок, посилання для браузера |

Під кожною витратою є кнопки: **Категорія**, **Разова**, **Це витрата партнера**, **Не рахувати** (для mono) або **Видалити**.

## Як рахуються операції з monobank

- **Витрати** йдуть у категорію за MCC-кодом магазину. Коли ти міняєш категорію, бот запамʼятовує магазин.
- **Поповнення та повернення** пропускаються.
- **Перекази на картки** потрапляють у «Не враховано», бо часто це гроші одне одному. Якщо так платиш оренду, натисни під повідомленням «🏠 Оренда». Бот запамʼятає отримувача, і наступного місяця такий переказ одразу піде в оренду.
- **Схоже на вже внесене вручну** (та сама сума ±1 день): теж «Не враховано», щоб не рахувати двічі.
- Раз на 5 хвилин бот звіряє виписку на випадок, якщо вебхук загубився. monobank дозволяє 1 запит на хвилину, тому кілька карток підтягуються по черзі.

## Оновлення коду

```bash
npx wrangler deploy
```
Дані та налаштування при цьому зберігаються. `./setup.sh --keep-bot` повторює налаштування без повторного вводу токена бота.

## Файли

- `src/worker.js`: сервер (API, бот, вебхук monobank, cron).
- `public/`: застосунок (`index.html`, `app.js`, `style.css`) і спільна логіка `shared.js` (категорії, MCC, розрахунок бюджету).
- `.secret`: внутрішній ключ. Не видаляй: від нього залежать адреси вебхуків.
